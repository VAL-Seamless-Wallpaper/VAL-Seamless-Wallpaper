VAL — Обои бесшовные / версия 1.0

Что уже есть:
- многостраничный сайт;
- каталог, коллекции, дизайнеры, шоурум, как заказать, о VAL, контакты;
- предварительный калькулятор по ширине/высоте/цене/запасу;
- форма заявки;
- резервное сохранение заявки в localStorage, если сервер недоступен;
- заготовка Netlify Function для Telegram;
- единый config.js для базовых настроек.

Рекомендуемый бесплатный запуск:
1. Создать аккаунт GitHub.
2. Создать новый репозиторий, например val-site.
3. Загрузить содержимое этой папки в репозиторий.
4. В Netlify выбрать Add new project -> Import an existing project -> GitHub -> выбрать val-site.
5. Build command оставить пустым, Publish directory: .
6. После публикации Netlify даст бесплатный адрес вида https://....netlify.app
7. Позже подключаем собственный домен.

Telegram:
- В Netlify -> Project configuration -> Environment variables добавить TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID.
- Токен бота никогда не хранить в HTML/JS.

Редактирование:
- На компьютере можно редактировать файлы прямо в GitHub через кнопку Edit.
- После сохранения Netlify автоматически опубликует изменения.
- assets/config.js: контакты и базовая цена.
- assets/app.js: тексты, коллекции и калькулятор.
- assets/style.css: дизайн.

Важно:
Эта версия не хранит заявки в общей базе без подключения сервера. Для production следующим этапом подключить Telegram + базу/CRM + загрузку фото.
